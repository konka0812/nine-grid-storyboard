# Narrative / Comic Intake

用于短剧、漫剧、剧情预告、小说可视化和剧本片段分镜。

## 先回答八个问题

1. 场景在哪里，时间是什么？
2. 场景里有谁？
3. 每个人想要什么？
4. 第一帧观众看见什么？
5. 哪个动作或发现改变局面？
6. 冲突升级还是缓解？
7. 最后一帧观众应该明白什么？
8. 是否需要钩子、反转、留白或收束？

## 参考图用途

| 用途 | 能控制 | 不应顺便控制 |
| --- | --- | --- |
| 角色身份 | 脸型、体型、发型、稳定识别标记 | 临时姿势、场景、灯光 |
| 造型状态 | 本场服装、伤损、湿污、破损 | 新人物、新场景 |
| 场景地理 | 入口、区域、方向、固定道具 | 人物情绪、剧情结果 |
| 构图 | 占画比例、视线位置、留白 | 人物身份 |
| 起始帧 | 本镜开始构图和状态 | 终点动作 |
| 结束帧 | 本镜结束状态 | 新发明后果 |
| 风格 | 色彩、光比、景深、笔触 | 角色身份、剧情 |

没有真实参考图时，不要伪造参考；把人物长相、服装、空间和光线写成静态视觉锚点，并标注“无参考图”。

## 连续性检查

1. 同一人物在九格中的服装和识别标记是否一致。
2. 人物位置是否能通过可见移动解释。
3. 视线是否与空间方向一致。
4. 持物是否凭空出现或消失。
5. 开门、坐下、转身、拿起等动作是否有完成过程。
6. 上一格终点是否等于下一格起点。
7. 台词是否由可见人物承载。
