# Narrative & Comic Nine-Beat Templates

## 短剧 / 剧情片段九拍

适用于一个场景、一个冲突、一个转折。

| 格 | 职责 | 写法 |
| --- | --- | --- |
| 01 | Establish | 建立空间、时间、光线和主要人物。 |
| 02 | Desire | 显示人物想要什么，或当前失衡。 |
| 03 | Contact | 人物与对象、他人或信息接触。 |
| 04 | Read | 观众看见第一反应。 |
| 05 | Pressure | 外界压力、阻碍或误解出现。 |
| 06 | Decision | 人物做出可见选择。 |
| 07 | Action | 执行选择，发生主要动作。 |
| 08 | Consequence | 展示结果、代价或情绪余波。 |
| 09 | Hook / Resolution | 留钩子、反转、收束或新问题。 |

不是每个片段都要有九次反转。可以合并，但每格仍要有独立职责。

## 漫剧 / Comic Page 九拍

| 格 | 职责 |
| --- | --- |
| 01 | Opening panel：空间和主角。 |
| 02 | Attention：让读者看见关键对象。 |
| 03 | Contact：接触、发现、对话开始。 |
| 04 | Reaction：表情、身体或环境反应。 |
| 05 | Turn：信息、冲突或情绪反转。 |
| 06 | Escalation：动作升级。 |
| 07 | Decision：选择路径。 |
| 08 | Impact：动作命中、真相揭示或代价出现。 |
| 09 | Aftermath / Hook：收束或下一场钩子。 |

Comic page 提示词必须强调：

```text
A 3x3 comic drama storyboard page with nine panels.
Read order: left-to-right, top-to-bottom.
Thin ink panel borders, clear white gutters.
Same characters, costumes, hairstyles, color palette and lighting logic across all panels.
```

但视频阶段必须改写成真实场景动作，不能写“镜头扫过漫画页”。

## Lifestyle / Travel 九拍

| 格 | 职责 |
| --- | --- |
| 01 | Arrival：进入环境。 |
| 02 | First glance：第一眼吸引物。 |
| 03 | Grounding：地面、材质、天气或声音。 |
| 04 | Human scale：人物与环境的关系。 |
| 05 | Local detail：有地方感的物件或纹理。 |
| 06 | Encounter：一次相遇、动作或停顿。 |
| 07 | Quiet turn：情绪转折或留白。 |
| 08 | Wide context：拉开空间。 |
| 09 | Memory frame：收束成一张可记住的画面。 |
