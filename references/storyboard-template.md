# 3×3 Storyboard Keyframe Sheet Template

用于产品、物件、短剧、漫剧、旅行和生活方式片段。模式不同，九格职责不同；版式和连续性要求相同。九格共同覆盖一个 `3-15s` 片段。

## 九格计划字段

每格必须写成：

```markdown
### SHOT-01 · <短名>
- 来源/覆盖：
- 职责：
- 目的：
- 起点：
- 动作：
- 终点：
- 摄影机：
- 时间范围：
- 情绪/信息变化：
- 风险：
- 参考用途：
- 声音/台词：
```

`动作` 只保留一个主要变化。若确实没有主体动作，写 `无主体动作；仅光影/氛围变化`。所有 `时间范围` 必须连续，且总时长等于 `3-15s`。

`来源/覆盖` 写这一格承担了哪个用户要求、剧本文本、卖点或声音；没有来源的装饰格应删除。`声音/台词` 没有声音时写 `无`，不要留空。

## 产品 / 物件九格骨架

| 格 | 通用职责 | 说明 |
| --- | --- | --- |
| 01 | Hero establish | 识别产品类型和气质。 |
| 02 | Ambient reveal | 用光、雾、阴影或环境做引入。 |
| 03 | Full product | 完整轮廓和比例。 |
| 04 | Signature material | 主材质、工艺或色彩层级。 |
| 05 | Key detail | 按键、接口、屏幕、纹理或结构。 |
| 06 | Function beat | 开合、点亮、折叠、装配等主变化。 |
| 07 | Use / scale | 使用状态、手持尺度或空间关系。 |
| 08 | System / context | 配件、生态、环境或收纳。 |
| 09 | Hero hold | 结尾定格，给剪辑留活口。 |

## 短剧 / 漫剧九格骨架

| 格 | 通用职责 | 说明 |
| --- | --- | --- |
| 01 | Establish | 空间、时间、光线和主要人物。 |
| 02 | Desire / imbalance | 人物想要什么，或当前关系失衡。 |
| 03 | Contact | 与人、物、信息或障碍接触。 |
| 04 | Reaction | 可见的情绪、身体或空间反应。 |
| 05 | Pressure | 外界压力、阻碍或误解。 |
| 06 | Decision | 人物做出可见选择。 |
| 07 | Action | 执行选择，发生主要动作。 |
| 08 | Consequence | 结果、代价或情绪余波。 |
| 09 | Hook / resolution | 留钩子、反转或收束。 |

## Lifestyle / Travel 九格骨架

| 格 | 通用职责 | 说明 |
| --- | --- | --- |
| 01 | Arrival | 进入环境。 |
| 02 | First glance | 第一眼吸引物。 |
| 03 | Grounding | 地面、材质、天气或声音。 |
| 04 | Human scale | 人与环境的关系。 |
| 05 | Local detail | 有地方感的细节。 |
| 06 | Encounter | 相遇、动作或停顿。 |
| 07 | Quiet turn | 情绪转折或留白。 |
| 08 | Wide context | 拉开空间。 |
| 09 | Memory frame | 可记住的收束画面。 |

## 3×3 图像提示词模板

```text
A clean 3x3 storyboard keyframe sheet for one continuous [3-15] second
[PRODUCT VIDEO / SHORT DRAMA / COMIC DRAMA / LIFESTYLE FILM].
Read order: left-to-right, top-to-bottom.
Nine separate panels with clear borders and clean gutters.

Subject / story facts:
[PRODUCT IDENTITY OR CHARACTER IDENTITY], [SPACE], [STATE], [KEY OBJECTS], [LIGHTING], [PALETTE].

Panel 1 (top-left): [SHOT-01 time range, visible start state, one main change, camera intention].
Panel 2 (top-center): [SHOT-02 time range, visible start state, one main change, camera intention].
Panel 3 (top-right): [SHOT-03 time range, visible start state, one main change, camera intention].
Panel 4 (middle-left): [SHOT-04 time range, visible start state, one main change, camera intention].
Panel 5 (middle-center): [SHOT-05 time range, visible start state, one main change, camera intention].
Panel 6 (middle-right): [SHOT-06 time range, visible start state, one main change, camera intention].
Panel 7 (bottom-left): [SHOT-07 time range, visible start state, one main change, camera intention].
Panel 8 (bottom-center): [SHOT-08 time range, visible start state, one main change, camera intention].
Panel 9 (bottom-right): [SHOT-09 time range, final visible state, hero hold / hook / consequence].

Style: professional previsualization, [LIGHTING STYLE], [BACKGROUND], consistent perspective system,
muted production-board palette, thin ink panel borders, clear white gutters.

Consistency rules:
Keep the same subject identity, silhouette, proportions, materials, colors and visible components
across all nine panels. For characters, keep face shape, hairstyle, costume, body proportions,
spatial position, gaze logic and held props consistent unless a panel explicitly shows a state change.
Do not redesign the subject. Do not add new buttons, ports, screens, accessories, characters,
text, watermarks or logos unless explicitly requested.
Each panel is a separate shot frame separated by clear gutters.
The nine panels form one continuous time chain, not nine independent posters.
```

## 文字标签

如果生成器文字稳定，可在每格下方加小标签 `01` 到 `09`。

如果生成器容易写错字，使用：

```text
No labels, no numbers, no text, no watermark in the storyboard sheet.
```

阅读顺序仍必须保持左到右、上到下。

## 审查清单

1. 是一张 3×3 分镜页，不是普通单幅插画。
2. 九格边框清楚，留白稳定。
3. 主体轮廓、比例、材质、颜色九格一致。
4. 角色/产品的部件数量没有变化。
5. 每格能对应到 `SHOT-...`。
6. 相邻两格在景别、角度、动作或信息上至少有一项变化。
7. 没有新增文字、logo、人物、手部、配件或功能。
8. 分镜页不是最终海报；它是可审查的镜头方案。
