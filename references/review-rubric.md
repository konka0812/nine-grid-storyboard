# Review Rubric

用于给生成的九宫格和视频做快速质量判断。它是审查工具，不是新的工作流。

## 分值

每项 0-3：

| 分数 | 标准 |
| --- | --- |
| 0 | 不可用；主体识别失败、严重变形或动作无法理解。 |
| 1 | 有明显问题，需要回上游修改。 |
| 2 | 有小瑕疵，可通过剪辑或提示词局部修正接受。 |
| 3 | 达到提案或发布质量。 |

## 权重

| 维度 | 权重 | 检查点 |
| --- | ---: | --- |
| 主体身份 | 25% | 产品轮廓、比例、部件数量；或角色脸型、发型、体型、服装、识别标记。 |
| 材质/造型 | 15% | 产品材质和颜色层级；或角色服装、湿污、破损等状态。 |
| 镜头逻辑 | 20% | 景别变化有动机；相邻格不重复；无无理由跳切。 |
| 动作因果 | 15% | 开合、使用、移动、发现等动作有起点、过程和终点。 |
| 叙事完整 | 15% | 建立、发展、转折、收尾完整；用户要求的信息有格子承担。 |
| 技术缺陷 | 10% | 闪烁、撕裂、多余物体、文字乱码、分镜边框混入视频。 |

加权总分：

```text
Identity*25 + Material/Costume*15 + Camera*20 + Action*15 + Narrative*15 + Defect*10
```

结果为百分制。

## 九宫格审查

先回答：

1. 是否有 9 个清晰格？
2. 阅读顺序是否左到右、上到下？
3. 每格是否能对应到 `SHOT-...`？
4. 主体身份是否九格一致？
5. 相邻格是否有独立职责？
6. 每格是否只承担一个主要变化？
7. 时间范围是否连续且总时长为 3-15s？
8. 是否出现文字乱码、多余 logo、额外部件？
9. 是否把最终海报误当分镜？

任一硬伤先修分镜，不进入视频。

## 视频审查

第一遍关掉声音看：

1. 主体是什么？
2. 观众能记住什么？
3. 镜头是否顺？
4. 结尾是否成立？

第二遍逐段暂停：

1. 检查主体比例和部件数量。
2. 检查材质或服装是否漂移。
3. 检查动作是否缺起点或终点。
4. 检查分镜边框、编号、纸纹是否混入视频。
5. 检查文字和水印。
6. 多片段时核对 Carry-in 与上一段 Carry-out。

第三遍开声音：

1. 台词是否完整。
2. 发声时间是否落在计划区间。
3. 声源是否可见或明确。
4. 环境声是否引入无来源事件。

## 常见缺陷

| 缺陷 | 原因 | 处理 |
| --- | --- | --- |
| 主体变形 | 身份锚点不足。 | 强化 Subject Bible；有原图时增加主体身份参考。 |
| 按钮变多 | 数量没有进红线。 | 写入事实表和禁止项。 |
| 镜头扫分镜 | 把九宫格当实物。 | 改成 GRID_SHOT_PLAN 参考语言。 |
| 材质漂移 | 只写颜色没写表面反应。 | 补哑光、高光、透明、织物等。 |
| 动作没逻辑 | 一格塞多个变化。 | 回到动作账本，一格一个主要变化。 |
| 时间超标 | 对白或动作预算不足。 | 回到覆盖表；必要时讨论拆分。 |
| 结尾乱飘 | 没写 hero hold。 | 明确终点停留 0.3-0.8 秒。 |
