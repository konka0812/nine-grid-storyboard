# Review Gates

中间产物比直接成片更容易讨论。先审九宫格，再烧视频算力。

## 阶段门

| 阶段 | 通过条件 |
| --- | --- |
| 1. Facts | 主体、场景、动作、禁止项没有未解释的发明。 |
| 2. Coverage | 用户必须出现的信息都有格子承担，时间预算成立。 |
| 3. Storyboard Plan | 九格职责清楚，起止边界连续。 |
| 4. Image Prompt | 四段式完整，可直接复制，没有内部流程语。 |
| 5. Generated Grid | 九格结构、身份、连续性和风格通过审查。 |
| 6. Video Prompt | 时间、动作、参考用途和禁止项完整。 |

未通过上一阶段，不进入下一阶段。

## 九宫格硬伤

任一问题出现，先修分镜图：

1. 不是 3×3，或格子和留白不清楚。
2. 阅读顺序不明。
3. 主体身份、比例、部件数量变化。
4. 角色换脸、换发型、换服装。
5. 关键道具凭空出现或消失。
6. 相邻格没有可见变化。
7. 某格承担多个主要动作。
8. 时间链断开。
9. 新增文字、logo、水印、人物或配件。
10. 九格像九张海报，不像一个片段的关键帧。

## 视频硬伤

任一问题出现，重生成或回上游修分镜：

1. 主体变形或身份漂移。
2. 分镜边框、编号、纸纹出现在视频里。
3. 关键动作缺起点或终点。
4. 镜头乱跳，没有注意力逻辑。
5. 台词超出时间预算或未由可见人物承载。
6. 产品部件数量变化。
7. 结尾没有落到指定画面。
8. 多片段 Carry-in 与上一段 Carry-out 不一致。

## 修改策略

一次只修一层：

| 问题 | 先改 |
| --- | --- |
| 主体身份错 | Facts / 原参考图 / 一致性红线。 |
| 九格结构错 | Sheet Contract。 |
| 动作顺序错 | Storyboard Plan 和时间范围。 |
| 风格漂移 | Style Bible。 |
| 视频镜头乱 | Dynamic Description。 |
| 结尾漂移 | Static Description 和结尾 hold。 |

不要在同一轮同时大改事实、风格、镜头和动作；否则无法判断哪层改动有效。
