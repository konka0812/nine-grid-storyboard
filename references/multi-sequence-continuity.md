# Multi-Sequence Continuity

只有用户确认拆分后，才生成多个九宫格。每个 `SEQ` 仍然是一个可单独提交的 3-15 秒片段。

## Master Breakdown

```markdown
# Master Breakdown

## Global Facts
- 主体身份：
- 服装 / 材质：
- 场景：
- 光线方向：
- 调色板：
- 关键道具：
- 空间轴线：
- 禁止项：

## SEQ-01
- 时长：3-15s
- 目标：
- Carry-in：
- 九格职责：
- Carry-out：
- 转 SEQ-02：连续接 / 硬切 / 省略 / 换场

## SEQ-02
- Carry-in：必须复制 SEQ-01 Carry-out
...
```

## Carry 状态必须具体

不要只写“角色在店里”。至少写：

1. 位置。
2.朝向。
3. 视线。
4. 双手和持物。
5. 服装状态。
6. 关键道具状态。
7. 光线。
8. 剪辑留尾。

示例：

```text
SEQ-01 Carry-out：
角色站在旧木桌左侧，身体朝桌角，视线落在摊开的信纸上；
右手食指压信纸下缘，左手提收起的伞；外套右肩有湿痕；
桌灯从右前方照亮信纸，窗外冷蓝光在背景。末尾保持 0.4s。
```

## 转场类型

| 类型 | 规则 |
| --- | --- |
| 连续接 | 下一格第一画面重复上一段 Carry-out，动作可继续推进。 |
| 硬切 | 世界状态不变，允许景别和机位变化。 |
| 省略 | 时间被跳过，必须有可见状态差异和可理解因果。 |
| 换场 | 地点或时间改变，Global Facts 中固定身份和道具，重新建立空间。 |

硬切不能悄悄改变持物、服装、灯光方向或未说明的剧情状态。

## 生成顺序

1. 用户确认 Master Breakdown。
2. 生成 SEQ-01 九宫格。
3. 审查 SEQ-01 九宫格，确认 Carry-out。
4. 生成 SEQ-01 视频提示词。
5. 对 SEQ-02 重复；其第一格必须表现已确认的 SEQ-01 Carry-out。

可以批量写计划，但不要在上一段 Carry-out 未确认时批量生成后续视频。

## 尾帧锚点

如果目标工具支持：

1. 可把上一段实际视频尾帧作为 `CARRY_IN_ANCHOR`。
2. 它只锁定上一段结束状态。
3. 它不能替代本段九宫格，也不能发明新动作。
4. 默认提交仍然是“本段九宫格 + 本段完整提示词”。

## 剪辑留尾

每个序列的视频提示词可以让结尾停留 `0.3-0.8s`，给剪辑留活口。不要把这个停留写成新的剧情动作。
